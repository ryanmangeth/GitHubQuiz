Como funciona a reciclagem?

A reciclagem envolve diferentes etapas, que podem incluir a coleta, a separação, o processamento e a transformação de resíduos em novos materiais.

O processo varia de acordo com o tipo de material e com as tecnologias utilizadas.

  • ✓ Coleta dos resíduos recicláveis.
  • ✓ Separação dos materiais.
  • ✓ Encaminhamento para reciclagem.
  • ✓ Processamento e transformação.
  • ✓ Reutilização como matéria-prima.
