PLANEJAMENTO DIGITAL

Como colocar o EcoCiclo na internet?

Para disponibilizar um site na internet, é necessário escolher uma plataforma de hospedagem e, opcionalmente, registrar um domínio personalizado.

A hospedagem é o serviço responsável por disponibilizar os arquivos do site para os visitantes.

Já o domínio é o endereço utilizado para acessar o site, como, por exemplo, ecociclo.com.br.

Como o EcoCiclo foi desenvolvido principalmente com HTML e CSS, ele pode ser publicado em serviços de hospedagem estática.

PROPOSTA DE ORÇAMENTO

Uma solução econômica para o EcoCiclo.

Considerando o caráter acadêmico e a estrutura estática do projeto, priorizamos baixo custo e facilidade de manutenção.

Solução recomendada: GitHub Pages + Registro.br

Hospedagem: GitHub Pages — R$ 0

Domínio: Registro.br — R$ 40/ano

Custo estimado no primeiro ano: R$ 40,00

Esse orçamento considera somente a hospedagem gratuita e o registro anual de um domínio .br, sem serviços adicionais.

Caso seja utilizado apenas o endereço gratuito fornecido pelo GitHub Pages, o custo de publicação pode ser de R$ 0.

JUSTIFICATIVA DA ESCOLHA

Por que escolher essa solução?

O GitHub Pages é uma alternativa adequada para projetos acadêmicos desenvolvidos com HTML, CSS e JavaScript executado no navegador.

Como o EcoCiclo não depende, nesta versão, de um banco de dados ou de um servidor de aplicação, a hospedagem estática atende às necessidades principais do site.

  • ✓ Baixo custo inicial.
  • ✓ Compatibilidade com páginas HTML estáticas.
  • ✓ Possibilidade de usar um domínio personalizado.
  • ✓ Integração com GitHub para armazenar o código.
  • ✓ Facilidade para atualizar os arquivos do projeto.
  • ✓ Suporte a conexões HTTPS.
PUBLICAÇÃO DO PROJETO

Etapas para colocar o EcoCiclo no ar.

A publicação pode ser realizada em algumas etapas, utilizando os arquivos desenvolvidos no VS Code.

1

Organizar os arquivos

Conferir todas as páginas HTML, o CSS e os arquivos de imagem, vídeo e áudio.

2

Criar um repositório

Criar um repositório no GitHub para armazenar o código-fonte do EcoCiclo.

3

Enviar o projeto

Adicionar os arquivos HTML, CSS e demais recursos ao repositório.

4

Ativar o GitHub Pages

Configurar a publicação nas opções do repositório e selecionar a origem do site.

5

Configurar o domínio

Caso seja contratado, configurar o domínio personalizado e os registros DNS necessários.

6

Testar o site

Verificar links, imagens, responsividade, acessibilidade e funcionamento das páginas.
